# EcoSort AI build workflow

## 1. Define
Confirm the target user, five core waste categories, and the SDG 12/13 connection.

## 2. Build MVP
Implement upload, classification, disposal guidance, history, and dashboard in `v1.0.0`.

## 3. Test
Test clear images, unclear images, unsupported files, missing API keys, and incorrect predictions.

## 4. Improve
Add local disposal rules, e-waste guidance, feedback capture, and better confidence handling.

## 5. Version
Create a new sibling folder for each major release. Keep previous folders unchanged.

## 6. Publish
Push the selected version to GitHub and deploy the app to Streamlit Community Cloud. Keep API keys in Streamlit secrets, never in GitHub.

## 7. Demonstrate
Prepare screenshots and a short recording so the project remains reviewable if the hosted app is sleeping.
